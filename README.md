# LING 個人品牌定位工具 V6

## V6 核心新增：BIO 人格分析
- 貼上目前 IG BIO 即可分析
- IG 黃金 4 行公式
  1. 你是誰：身份＋成果／經歷
  2. 你能提供什麼價值
  3. 人設溫度
  4. CTA 行動呼籲
- 四行各自評分
- BIO 總完成度
- BIO 人格判定
  - 專業價值型
  - 真實親近型
  - 行動轉換型
  - 生活自介型
- 自動找出最需要修改的兩個區塊
- 結合原本品牌定位資料，自動生成黃金 4 行 BIO
- 額外生成 3 種版本
  - 專業結果型
  - 真實共感型
  - 吸睛記憶型
- 一鍵複製優化 BIO
